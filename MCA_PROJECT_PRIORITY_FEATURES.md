# MaatriCare Priority Features

This is the short, high-priority feature list for the next phase of the product. These are the features that matter most for a usable MVP and should be completed before expanding into optional or longer-term work.

## Phase 1: Core MVP Features

### 1. Dashboard + daily tracking
- Pregnancy profile summary
- Estimated due date and current week
- Daily water tracking
- Prenatal vitamin tracking
- Activity tracking
- Sleep tracking
- Mood tracking
- Daily completion percentage
- Weekly care summary

### 2. Care task management
- View tasks for the current day
- Mark tasks complete/incomplete
- Create custom care tasks
- Edit custom tasks
- Delete custom tasks
- Task history by date range
- Recurring tasks

### 3. Appointment management
- Create appointments
- Edit appointments
- Delete appointments
- View appointment details
- Add appointment reminders
- Add provider and clinic information
- Appointment preparation questions

### 4. Symptom journal and private tracking
- Add symptom entries
- Choose common symptom options
- Record symptom severity
- Record date and time
- Add notes
- View journal history
- Edit entries
- Delete entries
- Filter by date range
- Keep entries private to the user
- Safety reminder for concerning symptoms
- Clear non-diagnostic disclaimer

### 5. Pregnancy milestone tracking
- Standard pregnancy milestone timeline
- Current trimester view
- Milestone completion state
- Custom milestones
- Milestone grouping by stage

## Phase 2: High-value supporting features

### 6. Weekly pregnancy guide
- [x] Show current pregnancy week content
- [x] Nutrition guidance
- [x] Safe activity guidance
- [x] Common body changes
- [x] Questions to ask a healthcare professional
- [x] Medically reviewed content

### 7. Notifications and reminders
- [x] In-app notification center
- [x] Appointment reminders
- [x] Daily care reminders
- [x] Weekly pregnancy reminders
- [x] Missed task reminders
- [x] Browser notifications

### 8. Account and privacy basics
- Login/logout
- Password reset
- Profile settings
- Display name updates
- Pregnancy profile updates
- Account deletion
- Secure session handling

## Phase 3: Future enhancements

### 9. Additional education content
- Resource library
- Postpartum resources
- Newborn preparation resources
- Hospital and emergency resources

### 10. Health data sharing and export
- Export pregnancy summary
- Export appointment history
- Export symptom history
- Generate PDF report
- Secure sharing links

### 11. Optional language and personalization
- Initial language support
- Localized dates and times
- Frontend translation improvements

### 12. AI and advanced features
- Only if health and privacy approvals are complete
- Educational summaries only
- No diagnosis or treatment decisions
- Mandatory disclaimers

## Recommended order of execution

1. Dashboard and daily tracking
2. Care tasks
3. Appointments
4. Symptom journal
5. Pregnancy milestones
6. Weekly pregnancy guide
7. Notifications
8. Security/privacy hardening
9. Advanced education and sharing features
10. AI features only after governance review

## Release focus

The product should first feel reliable, private, and useful for day-to-day pregnancy care before adding broader educational or AI features.
